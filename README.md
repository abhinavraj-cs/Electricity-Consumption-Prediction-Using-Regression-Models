# Electricity Consumption Prediction Using Regression Models

This repository contains an end-to-end Machine Learning project to predict monthly electricity consumption based on household features, appliance usage, and environmental factors.

## Dataset
- `electricity_consumption_dataset_20000.csv`: Dataset with 20,000 household electricity consumption records, including features like house area, family members, appliances, usage hours, and weather conditions.

## Model
- `electricity_consumption_prediction_using_regression_models.py`: Python script covering EDA, feature preprocessing, training multiple regression models (Linear Regression, Ridge, Lasso, Decision Tree, Random Forest, Gradient Boosting, XGBoost), hyperparameter tuning, model evaluation, and saving trained artifacts.
